# Словарь данных

Все записи в CSV сгенерированы скриптом `src/generate_data.py`. Названия полей сохранены в английском стиле, чтобы было удобно использовать их в SQL.

## `customers.csv` — покупатели

| Поле | Тип | Описание |
|---|---|---|
| `customer_id` | string | Уникальный идентификатор покупателя, первичный ключ. |
| `signup_date` | date | Дата регистрации; для покупателей с заказами не позже первого заказа. |
| `region` | category | Условный федеральный макрорегион покупателя. |
| `city` | category | Город покупателя, синтетическое значение. |

## `products.csv` — товары

| Поле | Тип | Описание |
|---|---|---|
| `product_id` | string | Уникальный идентификатор товара, первичный ключ. |
| `product_name` | string | Наименование товара. |
| `category` | category | Категория товара. |
| `list_price` | numeric | Справочная цена товара в рублях. |
| `unit_cost` | numeric | Смоделированная себестоимость единицы товара в рублях. |
| `popularity_weight` | numeric | Вес для генерации частоты выбора товара; техническое поле синтетической генерации, не KPI. |
| `is_active` | boolean | Флаг активности товара. |

## `orders.csv` — заказы

| Поле | Тип | Описание |
|---|---|---|
| `order_id` | string | Уникальный идентификатор заказа, первичный ключ. |
| `customer_id` | string | Идентификатор покупателя, внешний ключ на `customers`. |
| `order_date` | date | Дата заказа в 2025 году. |
| `sales_channel` | category | Канал оформления заказа. |
| `payment_method` | category | Способ оплаты. |
| `order_status` | category | Статус: `Доставлен`, `Отменён` или `Возврат`. |
| `discount_rate` | numeric | Базовая скидка заказа при генерации; итоговая скидка каждой товарной строки находится в `order_items.discount_pct`. |

## `order_items.csv` — строки заказа

| Поле | Тип | Описание |
|---|---|---|
| `order_item_id` | string | Уникальный идентификатор строки заказа, первичный ключ. |
| `order_id` | string | Идентификатор заказа, внешний ключ на `orders`. |
| `product_id` | string | Идентификатор товара, внешний ключ на `products`. |
| `quantity` | integer | Количество единиц товара в строке. |
| `unit_price` | numeric | Цена единицы товара до скидки в рублях. |
| `discount_pct` | numeric | Скидка товарной строки как доля от 0 до 1, например `0.10` = 10%. |

## Связи таблиц

- `customers.customer_id` 1 → N `orders.customer_id`
- `orders.order_id` 1 → N `order_items.order_id`
- `products.product_id` 1 → N `order_items.product_id`

Аналитическая модель собирается соединением всех четырёх таблиц. Уровень гранулярности `order_items` — одна строка товара внутри заказа.
